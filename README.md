## 题目说明

根据课堂测试提供的三张截图，还原一个新闻选项卡模块：三个栏目切换，每个栏目展示 9 条新闻，选中项使用红色边框、新闻前有蓝色方块项目符号。

三个栏目：

1. 最新投诉（默认显示）
2. 官方回应
3. 追踪调查

## 实现要点

- 页面结构、样式与脚本分离，样式写在 `index.html` 内的 `style` 中，切换逻辑位于 `js/news-tab.js`。
- 切换时先清除全部选项卡的选中状态，再设置当前项的选中状态与对应面板。
- 所有 CSS 类名、id、JS 变量均以 `sjs_` 开头。
- 使用 `role="tablist"`、`aria-selected` 等属性标注选项卡状态。

## 文件结构

- `index.html`：页面与样式
- `js/news-tab.js`：选项卡切换逻辑
